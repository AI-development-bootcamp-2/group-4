# Forum API

## Setup

```bash
cp .env.example .env
npm install
npm run dev
```

## Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start dev server with nodemon |
| `npm test` | Run all tests |
| `npm run lint` | Lint source files |
| `npm run seed` | Seed the database |

## Environment Variables

See `.env.example` for all required variables.
